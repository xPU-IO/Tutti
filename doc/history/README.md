# Roadmap History

This directory stores archived roadmap snapshots after the maintainer decides to switch the active version.

Rules:

- `Roadmap.md` at the repository root is the active roadmap
- Do not create a new version number automatically
- When the active version changes, archive the previous `Roadmap.md` here
- Every version snapshot must preserve:
  - `Feature Snapshot`
  - `Known Bugs Snapshot`
- Suggested file names:
  - `roadmap-v0.1.md`
  - `roadmap-v0.2.md`
  - `roadmap-v1.0.md`

The current active version is defined by the maintainer, not by automation.
